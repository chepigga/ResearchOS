# LAB278 — Structural Liquidity Transition (HVN → LVN → HVN), 2026-10-18

Дані: Binance BTCUSDT 5m (обсяг) 2020-11…2026-08; aggTrades посекундно (`BTCUSDT_sec.csv.zip`, реліз `btc`) 2026-03…08 — для валідації.
Профіль: 0.2% лог-біни, вікно 168/336/720 год до останньої закритої H1, згладжування 1.5 біна; HVN = піки з prominence ≥5% max; LVN = мінімум між сусідніми HVN ≤ lr·min(HVN), lr 0.5/0.7.

## Крок 0 — 5m-профіль проти aggTrades
Кореляція профілів 0.999+, HVN збігаються 99%, LVN 97–100%, POC 98–100% (±2 біни). 5m-обсяг достатній для 2021–26.

## Крок 1 — переходи проти випадкового блукання
Подія: M5 закрилась за LVN у напрямку від HVN_A (ціна торкалась A за 12 год) до HVN_B; 48 год, перший дотик A чи B.
Нуль: P(B першим) = dA/(dA+dB). **Відхилення від нуля −0.009…+0.016 (≈ 0.5 SE) на 2021–24 в усіх 6 конфігураціях.** Сама структура руху не передбачає.
Повернення до A ~43–46%, дохід до B ~51–54%, прискорення (B ≤ 6 год) ~30–38% — усе як у випадковому блуканні з цією геометрією.

## Крок 2 — + OI / L/S / taker / моментум / глибина LVN
Єдиний умовний фактор, що пройшов правило (z>2 на 2021–24 у базовій конфігурації W336/lr0.7 + той самий знак у ≥4/6 конфігурацій):
**натовп (z6) проти напрямку переходу, |z6| ≥ 0.5** — відхилення від нуля +0.060 (z 2.3), 6/6 конфігурацій; 2025–26 +0.068.
OI, taker, моментум, глибина LVN — шум або непослідовно.
Контроль: ті самі напрямок, умова натовпу й геометрія, але випадковий час (не LVN): відхилення −0.01…−0.07, net ≈ 0 або мінус → LVN-перехід додає таймінг.
