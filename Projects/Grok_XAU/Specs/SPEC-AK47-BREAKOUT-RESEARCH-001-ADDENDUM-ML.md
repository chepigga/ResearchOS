# SPEC-AK47-BREAKOUT-RESEARCH-001 — ADDENDUM: ML-селекція (C2-паттерн) замість ручного regime-фільтра
**Дата:** 2026-07-25
**Доповнює:** SPEC-AK47-BREAKOUT-RESEARCH-001 §3 (регімний фільтр)

## Мотивація
V15 M15 генерує ~26,735 breakout-кандидатів за 4 роки — того самого порядку, що C2 (3,716 угод / 291,801 епізодів за 42 міс). Достатньо N для walk-forward ML-тренування (на відміну від FT, де кандидатів лише ~1,300). AK47_XAU вже має ONNX-роадмап у беклозі (RandomForest режим-класифікатор) — це природний перший кандидат для нього.

## Уточнення аналогії з C2
Подібність НЕ в OCO/типі ордера (C2 — market entry на одиночний сигнал, без OCO). Подібність — у паттерні: популяція сирих кандидатів → причинні фічі → економічний лейбл → walk-forward selection топ-% → EA виконує вже відібрані сигнали.

## КРИТИЧНА залежність (посилює L12, не скасовує)
Лейбл (win/loss, net_R) для кожного кандидата ОБОВ'ЯЗКОВО рахується на tick-рівні / M1-з-спредом даних — НЕ на M5-bar reconstruction. Модель, натренована на лейблах з неправильної execution-моделі, вивчить артефакти шляху, не структуру ринку — гірше за просту grid-помилку, бо непомітніше.

## Дизайн (заміна §3 старого SPEC)
1. **Фічі (причинні, без lookahead):** сесія/година, ATR-ratio (короткий/довгий), відстань до swing high/low, spread-режим на момент candidate-бару, день тижня, D1/H4 bias (як фіча, не бінарний фільтр — F-X1 показав, що D1 як ЖОРСТКИЙ гейт не працює; як континуальна фіча модель сама вирішить вагу), попередній результат (streak).
2. **Економічний лейбл:** `y = (net_R > 0)` після реальних костів на фіксованій базовій геометрії (SL/TP з Кроку 1 SPEC — GO/REGIME конфігурація з §2 гріда, ЯКЩО вона є; інакше найпростіша economically sane геометрія RR≥1.5).
3. **Walk-forward:** тренування на trailing N місяців (rolling), передбачення на наступному місяці, повторити по всьому вікну (аналог 42 вікон C2).
4. **Селекція:** top-K% кандидатів за p_win (не фіксований поріг — trailing quantile, як C2 q0.96/90д).
5. **Гейт на EV, НЕ на AUC/accuracy** (F3 FXArena — AUC як критерій успіху ЗАБОРОНЕНИЙ як єдиний критерій).
6. **Baseline для порівняння:** проста geometria без ML-фільтра (з основного SPEC §2) І ручний regime-фільтр (ADX/ATR-ratio поріг). ML-модель повинна побити ОБИДВА на пре-registered порозі (наприклад +0.10R додаткового EV), інакше складність не виправдана — модель НЕ отримує права на впровадження просто за "вищий" результат, потрібен суттєвий приріст.

## Вердикт-правила (додаткові до §7 основного SPEC)
- **ML-GO:** walk-forward EV на всіх test-місяцях > baseline (проста геометрія) на ≥+0.10R, стабільно (≤1 мінусовий місяць з N), permutation пройдений на РІВНІ ВІДБОРУ (шафл лейблів, не тільки цін).
- **ML-NEUTRAL:** покращення є, але <+0.10R або нестабільне — залишити просту геометрію/ручний фільтр як canonical, ML observed but not deployed.
- **ML-NO-GO:** гірше за baseline — ML-шлях falsified для цього класу входу, ONNX-роадмап переоцінити.

## Послідовність виконання
Не паралельно з основним SPEC — ПІСЛЯ Кроку 1 (проста геометрія SL/TP/padding, tick-рівень, walk-forward). ML-адендум запускається лише якщо базова геометрія дає GO або REGIME (є на чому будувати відбір); якщо базова геометрія NO-GO — ML на порожньому фундаменті не рятує (той самий урок AK47_AI: фільтр не додає edge там, де вхід сам його не має).
