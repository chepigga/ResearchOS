=====================================================================
1. ПРАВИЛО NEAR-MISS (генеричне, для ВСІХ майбутніх лабораторій)
=====================================================================
Клітинка/кандидат, що провалила рівно ОДИН pre-registered гейт,
може отримати статус <NAME>(provisional) — PROMOTED TO VALIDATION —
якщо ВСІ умови виконані:
  NM1: перевищення проваленого ліміту <= 1% від значення ліміту
  NM2: перевага total R над бейзлайном >= +3% (self-consistent,
       тобто проти бейзлайна, перерахованого ТИМ САМИМ інстансом
       пайплайна)
  NM3: профіль місяців не гірший за бейзлайн; всі роки позитивні
  NM4: у звіті ЯВНО зафіксовано: гейт НЕ пройдено; provisional =
       квиток у validation-чергу, НЕ зміна канону і НЕ деплой
Заборони: правило не застосовується до >1 проваленого гейта;
ліміти NM1-NM3 не переглядаються під конкретного кандидата;
історичні вердикти не переписуються.
ЧЕСНА ПОЗНАЧКА: перше застосування (GEO**) — ретроактивне
(правило сформульовано після побаченого кандидата), тому його
validation-вимоги нижче — максимально жорсткі.

3. VALIDATION-СПЕКА GEO**-PROV (три стовпи, всі обов'язкові)
=====================================================================
ПЕРЕДУМОВА (блокуюча): P2 GitHub-реліз v1.1 з trade-фікстурами
(c2_trades_loop, trades GEO*, trades GEO**-prov TP2/60, таблиці
v009/v009b) + закріплений пайплайн. Причина: дрейф інстансів росте
(±1 -> ±9 угод), 0.078R на дрейфуючому інстансі не є виміром.
Контроль надалі = посигнальний diff проти фікстури (100% збіг або
локалізований баг), НЕ відтворення агрегатів, НЕ override.

СТОВП A — статистичний (на закріпленому пайплайні):
  GS5 rev-chrono для TP2/60 (деградація <= 20%)
  GS6 permutation-200 (процедура v009)
  GS7 (НОВИЙ) DD-еквівалентність: block bootstrap місячних блоків
      (>=2000 ресемплів) обох множин угод; вимоги:
      (i) P(DD_geo** > DD_geo* + 0.5R) < 0.05
      (ii) перевага total R тримається у >=95% ресемплів
      Провал GS7 = provisional знімається, TP2/60 -> каталог
      near-miss closed, без права повторної заявки на цих даних.

СТОВП B — self-consistency:
  Перепрогін пари {TP2/120, TP2/60} на закріпленому пайплайні;
  NM1-NM2 мають виконуватися і там (перевага не є артефактом
  інстанса B).

СТОВП C — форвардний A/B (безкоштовний, без зміни EA):
  Входи ContPrimary v1.20 на серпневому форварді ті самі для всіх
  геометрій; офлайн-реплей обох exit-політик (TP2/120 vs TP2/60)
  по реальних цінах live-входів за >= повний місяць.
  Вимога: TP2/60 не гірший за TP2/120 по total R і не гірший по
  максимальній просадці на форвард-вікні.

РІШЕННЯ ПІСЛЯ ТРЬОХ СТОВПІВ:
  Всі PASS + C2 склав серпневий екзамен -> GEO** стає геометрією
  v1.30-кандидата (замість GEO*), через retrain-протокол §5 v005.
  Будь-який FAIL -> GEO* канон, TP2/60 закривається назавжди
  (документований near-miss, повторних заявок немає).
