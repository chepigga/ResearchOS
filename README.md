# ResearchOS

Універсальний репозиторій для відтворюваних дослідницьких та інженерних проєктів.

## Принцип

Жоден підтверджений, спростований або архітектурно важливий результат не повинен залишатися лише в історії розмови.

## Навігація

- [GOVERNANCE.md](GOVERNANCE.md) — обов’язкові правила роботи.
- [RESEARCH_REGISTER.md](RESEARCH_REGISTER.md) — глобальний реєстр результатів.
- [MASTER_BACKLOG.md](MASTER_BACKLOG.md) — міжпроєктний backlog.
- [DECISIONS.md](DECISIONS.md) — індекс архітектурних рішень.
- [LESSONS_LEARNED.md](LESSONS_LEARNED.md) — узагальнені уроки.
- [Projects/](Projects/) — ізольовані проєкти.
- [Knowledge/](Knowledge/) — переносимі знання з посиланнями на джерела.
- [Templates/](Templates/) — обов’язкові шаблони.
- [Releases/](Releases/) — глобальні checkpoints.

## Git workflow

- `main`: стабільні документи, validated code, canonical results, releases.
- `research`: активні лабораторії та кандидатні результати.
- `feature/<project>-<task>`: нові лабораторії й великі зміни.

Початковий стан створено за `GOVERNANCE.md`. Імпорт `FXArena Research v1.2` очікує на вихідний checkpoint.
